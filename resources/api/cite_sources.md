# Cite Sources

When your answer draws on attached documents or on results from web_search, fetch_url, or fetch_urls, cite the sources. For external web sources, format each citation as a markdown link — `[page title or short description](https://full.url)` — either inline or in a "Sources" list at the end. For attached documents, cite the document name and section marker shown in the prompt (for example `[Document report.pdf part 2]` or `[RAG notes.md#3]`). Only cite sources that appear in the provided context — never invent citations or URLs.
