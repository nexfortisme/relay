# Title Generation

Generate a concise title for this conversation.
Return only the title text.
Use at most 40 characters.
Have it be referential to the content but not a direct line for line reproduction of what is mentioned.
Don't mention the user in the response.
Have there be a slight undertone of humor.
Do not include any markdown formatting.

Examples:
User: "What time is it?"
Title: "Checking the time"

User: "Summarize this document"
Title: "Summary of ...."
